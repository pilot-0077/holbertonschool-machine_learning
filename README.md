# ML

This repository contains my projects and exercises for the Holberton School Machine Learning curriculum.

It covers fundamental concepts of machine learning, data processing, and model implementation using Python and related libraries.

## Supervised Learning

### Word Embeddings

Directory: `supervised_learning/word_embeddings/`

- **0-bag_of_words.py** — implements a Bag of Words representation. It tokenizes sentences, builds or uses a vocabulary, and returns a NumPy matrix containing each vocabulary word's frequency in each sentence.
- **Concepts covered:** Natural Language Processing (NLP), tokenization, vocabulary features, and word-count vectors.
- **Dependency:** NumPy.
