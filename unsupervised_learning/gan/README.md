# Generative Adversarial Networks

This project covers Generative Adversarial Networks (GANs), a family of
generative models that learn to create new samples resembling a training
distribution.

## Learning Objectives

By the end of this project, I should be able to explain:

- What a Generative Adversarial Network is
- The roles of the generator and discriminator
- How adversarial training works
- How generator and discriminator losses are interpreted
- How latent vectors are transformed into generated samples
- Common challenges such as unstable training and mode collapse
- How convolutional GAN architectures are constructed
- How generated samples can be evaluated and improved

## Core Concepts

A GAN contains two neural networks trained in competition. The generator tries
to create realistic synthetic data, while the discriminator tries to
 distinguish generated samples from real ones. Through this adversarial process,
the generator gradually learns the structure of the training distribution.
