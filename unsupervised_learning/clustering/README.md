# Clustering

This project introduces unsupervised clustering techniques for grouping data
points according to similarity when class labels are not available.

## Learning Objectives

By the end of this project, I should be able to explain:

- What clustering is
- The difference between supervised classification and unsupervised clustering
- How K-means clustering works
- How cluster centroids are initialized and updated
- What intra-cluster distance means
- How to choose or evaluate the number of clusters
- How probabilistic and hierarchical clustering approaches differ

## Core Concepts

Clustering algorithms search for structure in unlabeled data by organizing
similar observations into groups. Different methods define similarity and
cluster structure differently, so the appropriate algorithm depends on the
shape, scale, and distribution of the data.
