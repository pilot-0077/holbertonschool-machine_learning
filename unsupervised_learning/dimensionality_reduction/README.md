# Dimensionality Reduction

This project covers techniques for reducing the number of features in a
dataset while preserving as much useful information as possible.

## Learning Objectives

By the end of this project, I should be able to explain:

- What dimensionality reduction is and why it is useful
- The difference between feature selection and feature extraction
- How Principal Component Analysis (PCA) works
- How variance is used to choose principal components
- How dimensionality reduction can support visualization and compression
- How nonlinear techniques can reveal lower-dimensional structure
- How to evaluate the effect of reducing dimensions

## Core Concepts

High-dimensional datasets can contain redundant or correlated information.
Dimensionality reduction transforms the original feature space into a smaller
representation that is easier to visualize, store, and process while retaining
important structure in the data.
