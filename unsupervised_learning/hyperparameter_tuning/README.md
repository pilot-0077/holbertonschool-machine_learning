# Hyperparameter Tuning

This project focuses on selecting effective hyperparameters for machine
learning models through systematic search and evaluation.

## Learning Objectives

By the end of this project, I should be able to explain:

- What hyperparameters are and how they differ from learned parameters
- Why hyperparameter tuning matters
- How grid search and random search work
- How validation data is used during model selection
- What Bayesian optimization is
- How Gaussian processes can support optimization
- How acquisition functions guide the search for promising configurations
- How to compare candidate models without leaking test information

## Core Concepts

Hyperparameter tuning searches over model configurations such as learning
rates, regularization strengths, architecture choices, or algorithm settings.
The objective is to find a configuration that performs well on unseen data
without using the final test set to guide model selection.
