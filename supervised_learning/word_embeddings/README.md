# Word Embeddings

This directory contains exercises for the Holberton School Machine Learning curriculum.

## 0. Bag of Words

**File:** `0-bag_of_words.py`

Implements `bag_of_words(sentences, vocab=None)`, which converts a list of sentences into a NumPy Bag of Words matrix.

- Converts text to lowercase and tokenizes words.
- Builds an alphabetical vocabulary when `vocab=None`.
- Uses the provided vocabulary when one is supplied.
- Returns the embedding matrix and the feature list.

**Dependency:** NumPy.
