# Classification - Holberton School

## 📌 Description
This project introduces the basic concepts of supervised learning and classification using a single neuron.

The first task implements a simple neuron that performs binary classification.

---

## 📁 Files

- `0-neuron.py`: Defines a Neuron class with:
  - Weight initialization using random normal distribution
  - Bias initialization
  - Activated output (A)

---

## 🧠 Concepts Covered

- What is a model
- Supervised learning
- Neuron structure
- Weights and bias
- Activation output

---

## ⚙️ Requirements

- Python 3.x
- NumPy
